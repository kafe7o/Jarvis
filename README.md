# J.A.R.V.I.S.

Личен AI асистент, който работи на твоя компютър и действа от твое име: говори с теб на глас, звъни и води разговори по телефона, праща SMS и имейли, приема плащания, следи задачи, напомняния и календар, търси в интернет и управлява компютъра.

Мозъкът е Claude (Anthropic API). Всичко останало са плъгини, които Claude вика като инструменти. Няма затворен списък с команди: каквото можеш да направиш ти на компютъра, може и Jarvis. Той вижда екрана и го управлява, води браузъра, пише и пуска код, а когато му липсва умение, си го написва сам.

## Какво може

| Област | Възможности |
|---|---|
| **Всичко останало** | **Вижда екрана** и управлява всяка програма с мишка и клавиатура; **води истински браузър** (сайтове, вход в акаунти, форми, поръчки), като логините се пазят; пише и пуска Python и shell; **сам си пише нови умения** и ги ползва веднага и след рестарт; **самостоятелни задачи по график** („всяка сутрин ми обобщавай пощата“, „следи цената на X“). |
| **Мисли и планира** | Сложните задачи ги разбива на **дърво от стъпки**, отмята ги и сменя плана, ако нещо се провали; на всеки час (настройва се) **сам преглежда** задачите, календара и пощата и те известява само ако има нужда; **помни всичко**: търси във всички ваши разговори досега; по подразбиране мисли на ниво `xhigh` (може и `max`). |
| **Всяко устройство** | **Уеб приложение** (чат + глас) за телефон, таблет, телевизор и всеки браузър; **други компютри** (лаптоп, работен PC) стават ръце на Jarvis с `jarvis node`: той ползва техния екран, файлове, команди и браузър; **Android телефон и Android/Google TV** през adb: приложения, YouTube, звук, бутони на дистанционното, екран, известия. |
| **Твоят мобилен номер** | През Android телефона звъни **от твоя номер**, вдига и затваря, праща SMS. Или пренасочи номера си към Twilio номера на Jarvis и той вдига вместо теб като секретар. |
| **Умен дом** | Лампи, климатици, щори, прахосмукачки, телевизори, камери (вижда картината), ключалки и аларма (с потвърждение) — всички марки през Home Assistant. |
| **WhatsApp, Viber, Gmail, Google Calendar** | Праща WhatsApp (през WhatsApp Web или API) и Viber (през Android телефона); чете, търси, отговаря и подрежда Gmail; добавя събития и праща покани в Google Calendar с Meet линк. |
| **Плаща на други** | PayPal към имейл/телефон и банков превод по IBAN през Wise — винаги с твоето „да“. |
| **Гласова защита** | `pip install -e ".[voicelock]"`, после `jarvis enroll-voice` записва гласа ти; после изпълнява команди и потвърждения само от теб. |
| **Глас като Jarvis и по телефона** | По телефона говори със същия неврален глас (на английски — британски, като във филма), не с роботизирания. |
| **iPhone** | „Hey Siri, Jarvis“ през Shortcuts, push известия (ntfy), уеб приложението на началния екран и пренасочване на номера. |
| **Разговор** | Текст в терминала, глас („Jarvis, …“), Telegram от телефона (текст и гласови съобщения). Помни разговора и факти за теб. |
| **Обаждания** | Звъни и казва съобщение; свързва те с някого (първо звъни на теб, после на другия); **води истински двупосочен разговор** с цел (запази маса, питай нещо, премести час) и ти докладва; **вдига входящите** обаждания като секретар и ти предава съобщението. |
| **SMS и имейл** | Изпраща и чете SMS, изпраща имейли с прикачени файлове, чете входящата поща. |
| **Плащания** | Линкове за плащане, фактури по имейл, баланс, списък с плащания, възстановяване, изплащане към банковата ти сметка (Stripe). |
| **Задачи и време** | Задачи с приоритет и срок; напомняния (еднократни и повтарящи се) на компютъра, по SMS, с обаждане или в Telegram; календар с внос/износ на `.ics` (Google, Outlook, Apple). |
| **Интернет** | Търсене в реално време и четене на страници. |
| **Компютър** | Shell команди, отваряне на програми/сайтове/файлове, файлове (четене, запис, местене, копиране, триене, търсене), клипборд, скрийншот, клавиатура и мишка, сила на звука, състояние на системата. |
| **Контакти и памет** | Указател (обаждане/имейл „на мама“), дългосрочна памет за предпочитания и хора. |

### Пълен достъп

`JARVIS_FILE_ROOTS=/` (или `C:\` на Windows) дава достъп до целия диск, а `JARVIS_TRUST_LOCAL=1` спира въпросите за команди, код, мишка и файлове.

### Потвърждения

Обаждания, SMS, имейли и всичко с пари **винаги** чакат твоето „да“ точно преди изпълнение — с кого, какво и колко. Така никой (включително грешно чута команда или чужд текст от интернет) не може да звънне или плати от твое име без теб. Същото важи и за поръчки, плащания и съобщения, направени през браузъра или екрана. Задачите по график никога не одобряват такова действие сами, а те питат. Командите, кодът, мишката и промените по файловете също питат, освен ако не сложиш `JARVIS_TRUST_LOCAL=1`.

## Инсталиране

**С един клик:** `bash install.sh` (Linux/macOS) или `.\install.ps1` (Windows). Инсталира всичко, пита те за ключовете на български (`jarvis setup`), може да запише гласа ти и да пуска Jarvis сам при включване на компютъра.

Ръчно:

```bash
git clone https://github.com/kafe7o/Jarvis && cd Jarvis
python -m venv .venv && source .venv/bin/activate     # Windows: .venv\Scripts\activate
pip install -e ".[all]"
playwright install chromium                            # браузърът, който Jarvis управлява
cp .env.example .env                                   # попълни ключовете
jarvis check                                           # кое е готово и какво липсва
```

За гласа трябва и `ffmpeg` (или `mpg123`) за възпроизвеждане на звук.

## Пускане

```bash
jarvis              # чат в терминала
jarvis voice        # гласов режим: кажи „Jarvis“ / „Hey Jarvis“
jarvis telegram     # бот в Telegram
jarvis web          # уеб приложението за телефон/TV/таблет + връзка с други компютри
jarvis node --hub http://<главния>:8770 --name laptop   # на друг компютър
jarvis serve        # всичко наведнъж: глас + Telegram + уеб + напомняния + телефон
jarvis daemon       # същото, но без терминал (за автостарт)
jarvis setup        # въвеждане на ключовете
jarvis enroll-voice # гласова защита
jarvis google-login # връзка с Google
jarvis ask "Какво имам утре?"
```

## На всички устройства

1. **Главният Jarvis** (компютърът, който е винаги включен): сложи `JARVIS_WEB_TOKEN` (дълъг случаен низ) в `.env` и пусни `jarvis serve` или само `jarvis web`.
2. **Телефон, таблет, телевизор:** отвори `http://<IP-на-главния>:8770/?token=<токена>` в браузъра и го добави на началния екран. Имаш чат, микрофон и потвърждения с бутон.
3. **Друг компютър:** инсталирай Jarvis там и пусни `jarvis node --hub http://<IP-на-главния>:8770 --name laptop` със същия `JARVIS_WEB_TOKEN`. Главният Jarvis вече може да работи и на него („на лаптопа отвори…“).
4. **Отвсякъде, не само у дома:** инсталирай [Tailscale](https://tailscale.com) на всички устройства и ползвай адреса от Tailscale. Така връзката е криптирана и не отваряш портове към интернет.
5. **Android телефон / TV:** включи *Wireless debugging* (телефон) или *ADB debugging* (TV) в Developer options, инсталирай `adb` на главния компютър и сложи `JARVIS_ADB_DEVICES=phone=192.168.1.20:5555,tv=192.168.1.30:5555`. При първата връзка устройството пита дали да позволи.

### iPhone

- **„Hey Siri, Jarvis“:** в Shortcuts направи пряк път с име „Jarvis“: *Dictate Text* → *Get Contents of URL* (`https://<адреса-на-Jarvis>/api/ask`, Method POST, Headers `Authorization: Bearer <JARVIS_WEB_TOKEN>`, Request Body JSON с поле `text` = Dictated Text) → *Get Dictionary Value* `answer` → *Speak Text*.
- **Известия:** инсталирай ntfy, абонирай се за темата от `NTFY_TOPIC`. Напомнянията, сигналите и молбите за потвърждение идват там; потвърждаваш в уеб приложението.
- **Обаждания:** пренасочване на номера към Twilio (по-долу).

### Вдигане на твоя номер

- **Вариант 1 (Android):** с телефона, свързан по adb, Jarvis вижда кой звъни, вдига, затваря и звъни от твоя номер.
- **Вариант 2 (всеки телефон):** пусни пренасочване „при заето / без отговор“ от мобилния си номер към Twilio номера на Jarvis (при повечето оператори в България: `**67*<номер>#` и `**61*<номер>#`). Тогава Jarvis вдига като секретар и ти предава съобщението.

## Нужни ключове и акаунти

| За | Какво | Откъде |
|---|---|---|
| Мозъка (задължително) | `ANTHROPIC_API_KEY` | console.anthropic.com |
| Обаждания и SMS | `TWILIO_ACCOUNT_SID`, `TWILIO_AUTH_TOKEN`, `TWILIO_PHONE_NUMBER`, `JARVIS_OWNER_PHONE` | twilio.com (купуваш номер) |
| Двупосочни и входящи разговори | `JARVIS_PUBLIC_URL` (напр. `ngrok http 8765`); в Twilio сложи „A call comes in“ → `<URL>/voice/incoming` | ngrok.com |
| Плащания | `STRIPE_API_KEY` | dashboard.stripe.com |
| Имейл | SMTP/IMAP хост, адрес, парола (за Gmail — App Password) | доставчика на пощата |
| Telegram | `TELEGRAM_BOT_TOKEN`, `TELEGRAM_OWNER_ID` | @BotFather, @userinfobot |
| Уеб приложение и други компютри | `JARVIS_WEB_TOKEN` | измисляш го сам |
| Android телефон / TV | `JARVIS_ADB_DEVICES` + `adb` | developer.android.com/tools/releases/platform-tools |
| Умен дом | `HOME_ASSISTANT_URL`, `HOME_ASSISTANT_TOKEN` | home-assistant.io (безплатно, на компютър или Raspberry Pi) |
| Google Calendar и Gmail | `GOOGLE_CLIENT_SECRET`, после `jarvis google-login` | console.cloud.google.com |
| Плащания към други | `PAYPAL_CLIENT_ID`, `PAYPAL_SECRET` и/или `WISE_API_TOKEN` | developer.paypal.com, wise.com |
| WhatsApp през API (по желание) | `WHATSAPP_TOKEN`, `WHATSAPP_PHONE_ID` | developers.facebook.com |
| Известия на телефона | `NTFY_TOPIC` | приложението ntfy |

Гласът (Whisper за разпознаване, неврален глас за говор, „hey_jarvis“ за събуждане) работи без допълнителни ключове.

## Архитектура

```
jarvis/
  brain.py          цикъл с Claude: инструменти, уеб търсене, резервен модел при отказ
  tools.py          регистър на инструментите и задължителните потвърждения
  store.py          SQLite: история, памет, задачи, напомняния, календар, контакти
  phone_agent.py    уебхук сървър за живи телефонни разговори (Twilio)
  plugins/          memory, tasks, system, browser, android, home, comms, messaging, google, payments, sendmoney, agent
  ~/.jarvis/skills/ умения, които Jarvis си е написал сам
  voice/            микрофон, Whisper, говор, wake word
  interfaces/       cli, voice, telegram
  hub.py, web/      уеб приложение и връзка с други устройства
  node.py           jarvis node: дава инструментите на друг компютър на главния Jarvis
```

Нова способност = нов файл в `jarvis/plugins/` с функция `register(registry, ctx)` и функции, декорирани с `@registry.tool(...)`; добави го в `BUILTIN` в `plugins/__init__.py`.
